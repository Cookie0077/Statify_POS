
## Frontend

Einfach in den `bin`-Ordner wechseln und die Datei `Statify.exe` ausführen.

## Backend

Gehe auf das GitHub-Repository `Statify_POS` https://github.com/Cookie0077/Statify_POS  und lade den Source Code herunter.

Öffne anschließend das Projekt mit PyCharm und erstelle eine virtuelle Umgebung (Venv). Installiere danach alle Abhängigkeiten aus der Datei `requirements.txt` in die Venv.

Sobald alles installiert ist, bist du startklar. Starte zuerst das Backend und führe anschließend die `Statify.exe` aus.
